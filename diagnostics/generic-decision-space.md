# Diagnostic: Generic Decision Space

Lint: **ED005**. Related: ED001; `reasoning/design-reasoning.md`; dominant-strategy (BG002) if one path wins.

**Evidence type:** experience + behavioral logs (P2–P4). P1 can hint at strategy collapse but not "feels generic."

## Symptom

Every turn feels like "pick highest VP"; game could be any Euro; no distinctive decision identity; players say "I've played this before" about a new design.

## Evidence to Collect

- Action labels stripped of theme — do choices still feel unique?
- Turn log: % of turns that are pure VP math vs trade-off / risk / social
- Mechanism skeleton: are 2–4 candidates differentiated or same skeleton?
- Target Player `motivation` — does play serve it?

## Diagnostic Questions

1. What decision would players miss if removed?
2. Is uniqueness only in components, not in choice structure?
3. Does genre profile demand a signature dynamic you lack?
4. Are alternatives orthogonal or same axis with different numbers?

## Likely Causes

| Cause | Tell |
|---|---|
| VP-only action economy | All actions convert to same currency |
| Safe portfolio of mechanisms | Worker place + set collect with no twist |
| Missing tension axis | No risk, denial, or timing |
| Over-balanced flatness | No sharp interesting edges |

## Candidate Interventions

| Fix | Risk |
|---|---|
| Add one signature constraint (hand limit, denial, timed window) | May feel bolted on |
| Split victory currencies | Complexity |
| Force irreversible commitment | AP / regret |
| Cut a generic subsystem; deepen one unique one | Scope cut pain |

## Minimal Experiment

**Variable:** one signature decision rule added or one generic subsystem removed.

**Metric:** ≥3/5 players describe the game in a non-generic phrase (not "another Euro").

**Success:** Design-state can name a unique decision identity in one sentence.

## Success Criteria

Blind description without theme still sounds like *this* game, not a category default.
