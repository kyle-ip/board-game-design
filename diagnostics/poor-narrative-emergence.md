# Diagnostic: Poor Narrative Emergence

Lint: **ED007**. Related: ED001, ED004; event / uncertainty chapters.

**Evidence type:** experience (P2–P4). Stories are human evidence only.

## Symptom

No emergent stories; sessions don't produce "remember when…"; logbook of scores without plot; theme events feel like random modifiers not chapters.

## Evidence to Collect

- Post-game story count (spontaneous)
- Whether events create causal chains (A led to B led to C)
- Comparison: flavor text read vs ignored
- Campaign/legacy expectations if genre claims narrative

## Diagnostic Questions

1. Can state changes be narrated as fiction without stretching?
2. Do players cause story beats, or only receive them?
3. Is information structured so arcs are visible?
4. Are "stories" only designer hopes in the brief?

## Likely Causes

| Cause | Tell |
|---|---|
| Stateless efficiency | Boards reset meaning each turn |
| Opaque RNG | Outcomes unexplained in fiction |
| No lasting marks | No permanence / scars / reputation |
| Parallel plots | No shared table narrative |

## Candidate Interventions

| Fix | Risk |
|---|---|
| Persistent board marks / scars | Bookkeeping |
| Causal event chains | Scriptedness |
| Public storytelling prompt at end | Feels forced |
| Asymmetric roles with arc goals | Balance / teach |

## Minimal Experiment

**Variable:** one persistence or causal-event rule.

**Metric:** ≥2 spontaneous "remember when" stories in debrief across 3 sessions.

**Success:** At least one story cites player choice as the cause.

## Success Criteria

Narrative emergence matches genre promise; not required for pure abstract euros.
