# Diagnostic: Theme–Mechanism Disconnect

Lint: **ED002**. Related: `theme-and-experience.md` Theme Coat, Ch mechanism fit matrix.

**Evidence type:** experience + teach clarity (P2–P4). Simulation cannot prove theme fit.

## Symptom

Theme feels pasted on; rules make sense as abstract game but not as the fiction; players invent house explanations that contradict lore.

## Evidence to Collect

- Teach: do theme verbs appear when explaining actions?
- Player quotes: "Why would a [role] do that?"
- Theme–mechanism matrix rating (Strong / OK / Weak) from concept-brief
- Blind teach: stranger invents wrong fiction for a mechanism

## Diagnostic Questions

1. Which mechanism most contradicts the theme verb?
2. Is disconnect cosmetic (names) or structural (incentives)?
3. Would the game play identically with a different theme?
4. Does genre profile expect thematic immersion or abstract elegance?

## Likely Causes

| Cause | Tell |
|---|---|
| Theme last | Mechanisms locked before theme chosen |
| Euro default | Efficiency loop under adventure theme |
| Flavor-only cards | Effects ignore theme tags |
| Victory mismatch | Win as accountant in explorer fantasy |

## Candidate Interventions

| Fix | Risk |
|---|---|
| Retheme names + icons to match existing loop | Still weak if incentives fight fiction |
| Replace one mismatched mechanism | Cascade balance |
| Add theme constraint on legal actions | Complexity |
| Soften theme claims; lean abstract | Honesty; may lose pitch |

## Minimal Experiment

**Variable:** one mechanism rewritten or renamed for theme fit.

**Metric:** Blind teach uses theme verb correctly ≥4/5 sessions.

**Success:** Players stop proposing contradictory fiction for that action.

## Success Criteria

Reskinning to another theme would feel wrong; decisions feel motivated by fiction.
