# External Resources (Condensed)

Agent-facing links only (~25 entries). Organized by **Agent Mode** — load this file when the user asks for tools, publishing, comparable games, or further reading.

**Do not load** [`references/web-resources.md`](references/web-resources.md) during normal design work (maintainer bibliography only).

Mechanism depth lives in `chapters/` (synthesized from Engelstein & Shalev). These URLs supplement companions — they are not a substitute for project templates or diagnostics.
