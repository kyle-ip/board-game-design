# External Resources (Condensed)

For the full curated index, see `references/web-resources.md`.

Top 3–5 entries per category. Each entry: value prop + URL.

## 1. Core Frameworks
- **MDA: A Formal Approach to Game Design** — Mechanics → Dynamics → Aesthetics, the foundational analysis framework. https://www.cs.northwestern.edu/~hunicke/MDA.pdf
- **A Vocabulary of Board Game Dynamics** — Taxonomic vocabulary filling MDA's Dynamics gap. https://arxiv.org/html/2403.10267
- **BloomWiki — MDA, Core Loop, Feedback** — MDA walkthrough across Bloom levels, good educational template. https://bloomwiki.org/index.php/Game_Mechanics,_the_Core_Loop,_and_the_MDA_Framework

## 2. Books
- **The Art of Game Design (Schell)** — 100+ lenses; extract as design self-review checklist.
- **Theory of Fun (Koster)** — Cognitive-science view of "why games are fun"; fun diagnosis.
- **Rules of Play (Salen & Zimmerman)** — Academic systematic textbook; "meaningful choice".
- **Building Blocks of Tabletop Game Design (Engelstein & Shalev)** — Mechanism encyclopedia; local PDF available.

## 3. Expert Columns
- **Mark Rosewater — Making Magic** — Card/TCG design gold standard, 20+ year archive. https://magic.wizards.com/en/news/making-magic
- **Stonemaier Games Blog (Stegmaier)** — Successful-publisher perspective on full chain. https://stonemaiergames.com/e-newsletter/blog/
- **Daniel Solis — Graphic Design for Board Games** — Icon systems and tabletop visual clarity. https://danielsolisblog.blogspot.com/
- **Think Like a Game Designer (Justin Gary)** — Design-thinking column, Ascension's designer. https://justingarydesign.substack.com/
- **Skeleton Code Machine** — Weekly deep dives on individual mechanisms. https://www.skeletoncodemachine.com/

## 4. Podcasts
- **Ludology Podcast** — Biweekly tabletop design theory, Engelstein co-founded. https://ludology.libsyn.com/webpage
- **Board Game Design Lab (Gabe Barrett)** — Designer interviews + hands-on videos. https://www.youtube.com/@BoardGameDesignLab
- **Decision Space Podcast** — Deep analysis on "decision space" design. https://www.decisionspacepodcast.com/

## 5. Tools
- **McDie** — Visual Monte Carlo dice simulator, no coding required. https://pmc.ncbi.nlm.nih.gov/articles/PMC8134935/
- **Component.Studio** — Data-driven card/board file generation from spreadsheet. https://component.studio/
- **NanDeck** — Scripted card generation, free. https://nandeck.com/
- **Tabletopia** — Web 3D tabletop simulator, supports public demos. https://tabletopia.com/
- **Tabletop Simulator** — Steam sandbox, most flexible digital playtest. https://www.tabletopsimulator.com/

## 6. Print Specs
- **Panda Graphic Design Guidebook V.4** — Industry-standard mass-production specs. https://pandagm.com/wp-content/uploads/2022/10/PandaGM-GraphicDesignGuidebook-V4-0922.pdf
- **The Game Crafter Design Guidebook 2023** — Leading POD vendor specs. https://s3.amazonaws.com/helpscout.net/docs/assets/561c5a919033600a7a36d5dc/attachments/643d87297133de139103ebc2/Design-Guide---2023.pdf
- **Dobeta Games — Print File Requirements** — Horizontal survey of all print spec categories. https://www.dobetagames.com/the-complete-guide-to-board-game-printing-file-requirements/
- **pnp-howto** — Open-source PnP file prep guide. https://github.com/ernierasta/pnp-howto

## 7. Communities
- **TTGDA — Resources** — Most authoritative directory; revisit first for updates. https://www.ttgda.org/blogs-and-videos
- **Cardboard Edison Compendium** — Designer article / resource directory. https://cardboardedison.com/directoryinfo
- **BoardGameGeek (BGG)** — Game database + designer forums; comparable game research entry point. https://boardgamegeek.com/
