# Genre Profile — Party

Low barrier, high social energy, short teach, often high player count. Fun > optimization.

## Core Experience

- **Aesthetics:** Fellowship, expression, sensation (laughter, surprise)
- **Player fantasy:** Perform, joke, compete lightly
- **Session:** 15–45 min; teach ≤5 min

## Typical Dynamics

- Simultaneous or fast turns; minimal downtime
- Rule questions = design failure at external playtests
- Hidden information for comedy, not deep deduction
- Score often secondary to moment-to-moment fun

## Mechanism Vocabulary

- Real-time or simultaneous selection (Ch 2)
- Set collection, pattern matching, word/association
- Light hidden roles (not full social-deduction depth)
- Input randomness for drama; avoid output randomness frustration

## Common Failure Modes

| Symptom | Diagnostic | Not usually |
|---|---|---|
| "Boring" / flat | `endgame-drag.md` (too long), `low-agency.md` (waiting) | Add euro engine |
| Rules confusion | `lint` BG014; simplify, don't add exceptions | More chrome |
| One player dominates | `kingmaking.md`, `dominant-strategy.md` | Heavy catch-up |
| Runs too long | `endgame-drag.md` | More phases |

## Playtest Frameworks by Stage

| Stage | Framework |
|---|---|
| Early | Scattershot — watch for laugh moments |
| Mid | Good-Bad-Meh — quote capture critical |
| Late | Blind Rulebook — must pass for external groups |

## Prototype Constraints

- Large type, minimal text on cards
- Prototype with generic art OK; clarity > beauty
- Test at target player count (often 6+)
