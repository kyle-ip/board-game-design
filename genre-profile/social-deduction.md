# Genre Profile — Social Deduction

Hidden roles, bluff, partial information, accusation/debate. Core loop is **belief formation**, not action economy.

## Core Experience

- **Aesthetics:** Challenge (deduction), narrative, fellowship (debate)
- **Player fantasy:** Lie, detect lies, survive accusation
- **Session:** 20–60 min; teach 5–10 min with example round

## Typical Dynamics

```text
Information → Belief → Social inference → Communication → Commitment → Trust/Betrayal
```

- Discussion phase is the game — not downtime
- Elimination / kingmaking risk high
- Balance is **information distribution**, not VP-equivalent
- First-player win rate is usually **irrelevant**

## Mechanism Vocabulary

- Hidden roles, hidden teams (Ch 6)
- Voting, accusation, elimination timing
- Partial revelation, mission structure (Resistance-style)
- Bluffing components without heavy rules

## Common Failure Modes

| Symptom | Diagnostic | Not usually |
|---|---|---|
| Dominant informant | `dominant-strategy.md` (info role) | More actions |
| Kingmaking on elimination | `kingmaking.md` | Score track |
| "Too random" | Often **role distribution**, not dice — audit setup | Add combat |
| Analysis paralysis | `analysis-paralysis.md` in discussion | More options |
| Boring | Weak discussion hooks — add stakes, not mechanisms | Worker placement |
