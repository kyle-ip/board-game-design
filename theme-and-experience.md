# Theme and Experience Design

Companion to mechanism chapters — **not** Building Blocks ch14. Use in **Create** mode with `templates/concept-brief.md`.

Mechanisms answer *how*; this file answers *what should it feel like* and *does the theme fit*.

## Experience-First Rule

1. Name 1–3 [MDA aesthetics](https://www.cs.northwestern.edu/~hunicke/MDA.pdf) in concept brief.
2. Sketch target **emotion curve** (below).
3. Only then pick mechanism codes (`reasoning/design-reasoning.md`).

Do not select mechanisms because they are fashionable — map to aesthetics.

## Emotion Curve

Sketch intensity (1–5) by phase:

| Phase | Target intensity | Design lever |
|---|---|---|
| Opening hook | 3–4 | Quick win, curiosity, role |
| Midgame tension | 3–5 | Scarcity, interaction, uncertainty |
| Pre-end spike | 4–5 | Race, reveal, contest |
| Resolution | 4–5 | Clear winner, celebration or groan |

Flat line at 3 = "fine but forgettable." Match curve to audience (party = spikes; euro = sustained 3–4).

Record in concept brief **Emotion curve** field.

## Theme–Mechanism Fit Matrix

Use when theme feels pasted-on. Score Fit: Strong / OK / Weak / Avoid.

| Theme family | Strong fits | Weak / avoid |
|---|---|---|
| **Exploration / adventure** | Hidden map, movement, push-your-luck, set collection | Pure abstract auction |
| **Fantasy / magic** | Variable powers, deck building, engine combos | Stock market simulation |
| **Sci-fi / space** | Tech trees, worker placement, area control | Trick-taking only |
| **Economy / trade** | Markets, auctions, open trading | Real-time dexterity |
| **History / civilization** | Engine building, area control, legacy | Pure party word game |
| **Horror / mystery** | Hidden roles, hidden movement, limited info | Perfect information optimization |
| **Co-op survival** | Shared threats, communication limits, escalation | Kingmaking PvP |

Pick **one primary theme verb** (explore, build, survive, trade, deduce) and align core loop verb.

## Low-Cost Narrative

Mechanisms frozen first; add flavor without rules bloat:

| Technique | Cost | Example |
|---|---|---|
| Flavor text on cards | Low | Names only, no rules |
| Event deck | Medium | 10–20 cards reshuffle timing |
| Scenario goals | Medium | One-shot objective cards |
| Hidden information as fiction | Low | "Secret mission" = hidden VP |
| Component naming | Low | Cubes → supplies, not "VP tokens" |

## Theme Coat Step

From `workflow.md` Stage 2: add theme **after** loop works. Checklist:

- [ ] Does theme explain **why** players take the core action?
- [ ] Would reskin to another theme break player intuition?
- [ ] Any mechanism that contradicts setting (friendly fire in cozy farming)?

If Weak fit in matrix → restructure before art, not after.
